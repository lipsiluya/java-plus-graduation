# Explore With Me (microservices)

## О проекте
`Explore With Me` — это микросервисное backend-приложение для платформы мероприятий.  
Система позволяет пользователям создавать события, искать их, отправлять заявки на участие, работать с категориями и подборками, а также получать рекомендации на основе пользовательских действий.

Проект создавался как выпускная работа, чтобы собрать не просто CRUD-приложение, а более приближенную к реальной разработке систему: с несколькими сервисами, централизованной конфигурацией, очередями сообщений и межсервисным взаимодействием.

### Что решает проект
- предоставляет API для работы с мероприятиями;
- разделяет публичные, пользовательские и административные сценарии;
- демонстрирует микросервисный подход к построению backend-систем;
- реализует recommendation-контур на основе действий пользователей.

### Стек технологий
- `Java 21`
- `Spring Boot`
- `Spring Cloud` (`Eureka`, `Config Server`, `Gateway`, `OpenFeign`)
- `PostgreSQL`
- `Kafka`
- `gRPC` + `Protobuf`
- `Avro`
- `Maven`
- `Docker Compose`

## Запуск
Краткая шпаргалка: сначала инфраструктура, затем прикладные сервисы.

### Системные требования
Для локального запуска понадобятся:
- `Java 21`
- `Maven`
- `Docker` и `Docker Compose`
- `PostgreSQL`
- `Kafka`

Если запускать инфраструктуру не через Docker, нужно вручную задать:
- `SPRING_DATASOURCE_URL`
- `SPRING_DATASOURCE_USERNAME`
- `SPRING_DATASOURCE_PASSWORD`
- `KAFKA_BOOTSTRAP_SERVERS`
